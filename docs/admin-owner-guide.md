# Admin owner guide

Start at **Setup** and complete business details, branding, branch, hours, delivery, menu, optional inventory, reviews, payments, printing, staff and go-live checks. The completion percentage is based on persisted configuration rather than a manual flag.

Daily opening routine:

1. Confirm branch, hours, product availability and low-stock alerts.
2. Open a register shift with the counted float.
3. Keep Orders and Kitchen open during service; confirm the connection indicator.
4. Use POS for counter sales and print receipts as required.
5. Receive purchases and record waste or count adjustments promptly.
6. Reconcile transactions, review exceptions, count the drawer and close the shift.
7. Review Dashboard/Reports and unresolved notifications.

Use OWNER sparingly. Give CASHIER only counter/register access and KITCHEN only kitchen workflow access. Never share accounts. Normal customers do not become admins. Database migrations, production environment secrets, live payment activation and physical printer commissioning should be handled by an authorized technical operator.
